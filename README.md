## About

DevOps / SRE focused on **reliability, automation, CI/CD, IaC and observability**, plus **AI agents (LangChain/LangGraph) and RAG**.
I build production-ready infrastructure, monitoring, and deployment pipelines—and I like shipping practical systems that scale.

**Core interests**
- **Cloud & SRE:** incident response, monitoring/alerting, troubleshooting
- **Platform & DevOps:** CI/CD, GitOps, IaC, automation
- **AI Engineering:** vertical agents, tool integration, retrieval + hybrid search
